Распознаватель — k-NN leave-one-out по extracted_frames.csv

Сравнивает точность распознавания для каждой из 4 стратегий выбора кадра. Использует k-ближайших соседей (k-NN) среди других кадров той же стратегии. Нормализация: запястье в начало координат, масштаб по расстоянию запястье → MCP среднего пальца.

Что делает leave-one-out 
Для каждой записи в датасете:
1. Берём её как тестовый пример.
2. Среди ВСЕХ остальных записей
   ТОЙ ЖЕ стратегии находим k
   ближайших по форме руки.
3. Голосуем по их меткам — это
   предсказание.
4. Сравниваем с истинной меткой.

Accuracy на стратегии =
   правильных / всего

Это стандартный способ
оценки на маленьких датасетах
без отдельной обучающей и
тестовой выборки.

Загрузите extracted_frames.csv

Файл выгружается из experiment.html.
