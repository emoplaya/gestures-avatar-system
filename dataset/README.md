# Датасет траекторий дактиля

Папка для CSV-логов жестов, записанных через `useTrajectoryLogger`. Этот датасет используется в экспериментах по проверке гипотезы об экстремумах Δ(t) (статья АИСТ).

## Цели по объёму

| Часть | Описание | Минимум | Желательно |
|---|---|---|---|
| Статика — буквы | Все 33 буквы русского дактиля × 5 повторов на участника × 3+ участника | 495 записей | 825 (5 уч.) |
| Динамика — буквы | Й, Р, Ц, Ч, Щ, Ы, Ь, Ъ × 5 повторов × 3+ участника | 120 | 200 |
| Слитный дактиль — слова | 10 слов × 3 повтора × 3 участника | 90 | 150 |

## Формат имени файла

**Обязательный формат:** `trajectory_<participant>_<label>_<rep>_<timestamp>.csv`

Примеры:
- `trajectory_p01_A_1_2026-04-26T14-30-00.csv` — буква А, участник p01, повтор 1
- `trajectory_p02_PRIVET_3_2026-04-26T15-12-00.csv` — слово ПРИВЕТ, участник p02, повтор 3
- `trajectory_p01_J_2_*.csv` — буква Й (динамическая), повтор 2

`participant` — короткий код участника, `p01`, `p02`, ... (никаких имён, чтобы можно было опубликовать датасет).

`label` — латинская транслитерация буквы или слова заглавными буквами:
- А=A, Б=B, В=V, Г=G, Д=D, Е=E, Ё=YO, Ж=ZH, З=Z, И=I, Й=J,
- К=K, Л=L, М=M, Н=N, О=O, П=P, Р=R, С=S, Т=T, У=U, Ф=F,
- Х=KH, Ц=TS, Ч=CH, Ш=SH, Щ=SHCH, Ъ=HARDSIGN, Ы=Y, Ь=SOFTSIGN, Э=EH, Ю=YU, Я=YA

`rep` — номер повтора (1..5).

`timestamp` — добавляется автоматически логгером, не трогать.

## Протокол записи

### Перед записью

1. Хорошее освещение, нейтральный фон, **руки видно полностью** (запястье + 5 пальцев).
2. Камера на уровне груди, расстояние ~50 см.
3. Никаких часов/браслетов на запястье — MediaPipe путается.
4. **Записываем ПРАВУЮ руку** (если участник левша — пометить в `participants.csv`, см. ниже).

### Запись одной статической буквы

1. Включить камеру, дождаться стабильного трекинга (3-5 секунд).
2. Поставить руку в **нейтральное положение** (расслабленная ладонь, пальцы естественно расставлены, ладонь к камере). Это будет baseline.
3. Нажать **«Старт лога»**.
4. Подождать 0.5 секунды (рука неподвижна) — это даёт чёткий нулевой baseline.
5. Плавно сложить букву → **зафиксировать на 1 секунду** → плавно вернуть в нейтральное.
6. Нажать **«Стоп»**.
7. Скачать CSV, переименовать по схеме выше.

### Запись динамической буквы (Й, Р, Ц, ...)

То же самое, но букву показываем **полностью с движением**, не дробим. Длительность жеста ~1.5–2.5 сек.

### Запись слитного дактиля (слово)

1. Подготовить ручную разметку: для слова «ПРИВЕТ» примерно знаешь, где какая буква.
2. После записи открыть CSV в `analyzer.html`, в поле «Ожидаемая строка» ввести `PRIVET`, подобрать порог HOLD так, чтобы экстремумы совпали с буквами.
3. **Сохранить ground truth** в `<filename>_truth.txt` рядом с CSV в формате:
   ```
   P 320
   R 580
   I 840
   V 1100
   E 1380
   T 1640
   ```
   Каждая строка: буква, момент в мс, когда она «зафиксирована» (плато на displacement или минимум velocity по визуальной оценке).

## Метаданные участников

Создать файл `participants.csv` в этой папке:

```
id,age,gender,handedness,is_native_dactyl,notes
p01,22,M,right,no,студент, обучен дактилю в проекте
p02,35,F,right,yes,владеет РЖЯ с детства
p03,28,M,left,no,записан зеркально
```

`is_native_dactyl=yes` — носитель РЖЯ, важно для контроля «спайдер-лапок» (носители фиксируют форму чище).

## Пайплайн обработки

```
[датасет/*.csv]
    ↓ загрузить в experiment.html
    ↓ нажать «Обработать все файлы»
    ↓ скачать extracted_frames.csv
    ↓ скармливаем в распознаватель (gestureRecognizer.js или DTW)
    ↓ accuracy / F1 на стратегиях { last, middle, min_velocity, max_displacement }
    ↓ → таблица в статью
```

## Контрольный список перед экспериментом

- [ ] Минимум 3 участника записаны
- [ ] Все 33 буквы статики × 5 повторов
- [ ] 8 динамических букв × 5 повторов
- [ ] 10 слитных слов × 3 повтора с ground truth разметкой
- [ ] `participants.csv` заполнен
- [ ] Имена файлов соответствуют шаблону
- [ ] Случайная выборка 20 CSV открывается без ошибок в `analyzer.html`

## Что считать «плохой записью» (брак)

- В записи >30% missing-кадров (трекинг сорвался)
- Длительность <500 мс (не успел зафиксироваться)
- В нейтральном положении (первые 0.5 сек) Δ от baseline > 0.05 (рука дрожала, baseline не чистый)
- Visible artifacts в `analyzer.html`: `delta_l1` имеет резкие пики, не объяснимые движением

Брак не удалять, а складывать в `dataset/_rejected/` — потом интересно проанализировать отдельно.
