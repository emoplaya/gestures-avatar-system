Эксперимент — пакетная обработка датасета

Принимает множество CSV-логов траекторий, для каждого применяет 4 стратегии выбора ключевого кадра (last, middle, min_velocity, max_displacement) и выгружает сводный extracted_frames.csv для дальнейшего распознавания и подсчёта метрик.

Парсинг имени файла

Пример: trajectory_p01_PRIVET_3_2026-04-26.csv
Участник = p01, метка = PRIVET, повтор = 3.

Параметры детекции

Запуск

Что делает каждая стратегия 
last           — последний валидный
                 кадр записи (= baseline,
                 если запись «жест → возврат»).

middle         — кадр на середине
                 временного окна.

min_velocity   — кадр в самом длинном
                 HOLD-сегменте по
                 каналу velocity (минимум
                 скорости — рука замерла).

max_displacement —
                 кадр в самом длинном
                 HOLD-сегменте по
                 каналу displacement
                 (плато на пике Δ от
                 baseline — поза
                 удерживается).
Формат extracted_frames.csv 
participant,label,rep,strategy,
t_ms,frame_idx,x0,y0,z0,...,x20,y20,z20

Каждая запись датасета даёт до 4
строк (по одной на стратегию).

Этот файл потом скармливается
скрипту распознавания.

Загрузите CSV-файлы датасета

Файлы должны быть из логгера траекторий (та же схема, что у analyzer.html).
Имена файлов задают участника, метку буквы/слова и номер повтора — формат настраивается слева.
